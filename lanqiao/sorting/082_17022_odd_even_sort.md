# 第 82 题：奇偶排序

## 题目信息

- 题目名称：奇偶排序【算法赛】
- 平台：蓝桥云课
- 平台题号：17022
- 题目链接：[点击查看题目](https://www.lanqiao.cn/problems/17022/learning/)
- 知识点：排序、自定义比较函数、分组思想

## 题目规则

按照以下规则对数组进行排序：

1. 如果两个数的奇偶性不同，奇数排在偶数前面。
2. 如果两个数的奇偶性相同，按照实际数值从小到大排列。

例如：

```text
输入：
6
4 1 3 2 6 5

输出：
1 3 5 2 4 6
```

## 解法一：奇偶分组

### 解题思路

分别使用两个 `vector` 保存奇数和偶数：

1. 遍历原数组。
2. 将奇数放入 `odds`。
3. 将偶数放入 `evens`。
4. 分别对两个数组进行升序排序。
5. 先输出所有奇数，再输出所有偶数。

因为题目规定奇数一定排在偶数前面，所以分组后分别排序即可。

### 复杂度分析

- 时间复杂度：`O(N log N)`
- 空间复杂度：`O(N)`

## 解法二：自定义排序比较函数

### 解题思路

使用 `sort` 的第三个参数传入自定义比较函数 `cmp`。

```cpp
sort(a.begin(), a.end(), cmp);
```

`cmp(x, y)` 的返回值表示：

> 是否应该把 `x` 排在 `y` 前面？

比较时分为两种情况。

### 情况一：奇偶性不同

如果 `x` 和 `y` 的奇偶性不同，奇数应该排在前面：

```cpp
if (x % 2 != y % 2)
{
    return x % 2 != 0;
}
```

比较结果如下：

| x | y | 返回值 | 排序结果 |
| --- | --- | --- | --- |
| 奇数 | 偶数 | `true` | x 排在前面 |
| 偶数 | 奇数 | `false` | y 排在前面 |

### 情况二：奇偶性相同

如果两个数都是奇数或者都是偶数，则按照数值升序排列：

```cpp
return x < y;
```

### 完整比较函数

```cpp
bool cmp(int x, int y)
{
    if (x % 2 != y % 2)
    {
        return x % 2 != 0;
    }

    return x < y;
}
```

### 复杂度分析

- 时间复杂度：`O(N log N)`
- 额外空间复杂度：`O(log N)`

## 两种解法对比

| 解法 | 优点 | 不足 |
| --- | --- | --- |
| 奇偶分组 | 思路直观，容易理解 | 需要额外使用两个数组 |
| 自定义比较函数 | 代码简洁，直接表达排序规则 | 需要理解比较函数的含义 |

## 易错点

### 1. 不要写反奇偶顺序

下面的写法会让偶数排在奇数前面：

```cpp
return x % 2 < y % 2;
```

因为偶数取模结果为 `0`，奇数取模结果为 `1`。

### 2. 不能使用小于等于

不能写成：

```cpp
return x <= y;
```

比较函数必须使用严格的小于关系，否则当 `x == y` 时，`cmp(x, x)` 仍会返回 `true`，不符合 `sort` 的比较规则。

## 总结

这道题可以使用分组排序，也可以使用自定义比较函数。

自定义比较函数的核心是：

- 奇偶性不同：奇数优先。
- 奇偶性相同：数值较小的优先。
